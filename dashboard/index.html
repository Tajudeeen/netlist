The product idea

Three layers of fact, kept separate

Not collapsed into one “is this safe” boolean. Each claim carries its own provenance and its own trust assumption.

01 / DERIVED

Read from the netlist

Gate count, circuit depth, and a flat gas estimate are decoded from the circuit's actual on-chain netlist bytes — trustless, because the facts are computed, not claimed.

trust: math + chain
02 / DECLARED

Attested by humans

Publisher and auditor attestations live in separate, versioned tracks. Re-attesting increments a counter, and every read checks the current netlist hash for staleness.

trust: named attester
03 / NETWORK

Live, never cached

Processor seal status and container activation are re-read at call time. Seal requires factory seal + beacon pin + factory ownership, shown as three independent claims.

trust: live RPC
